MODO EDICIÓN ACTIVO
- Arrastra elementos para moverlos.
- Rueda del ratón: Escalar ancho y alto.
- Shift + Rueda: Escalar solo ancho.
- Alt + Rueda: Escalar solo alto.
- Ctrl + Rueda: Escalar tamaño de fuente.
- Doble Click: Editar el texto.
- Suprimir / Retroceso: Eliminar elemento bajo el cursor.
- Ctrl + Shift + S: Copiar coordenadas al portapapeles.
- Ctrl + Shift + E: Salir del modo edición.
